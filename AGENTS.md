## Verification flow (critical order)

```
npm run typecheck
npm run lint
npm run build
npm test          # runs tsx scripts/verify-v6-all.ts (8 steps sequentially)
# Steps within verify-v6-all.ts:
# 1. tsc --noEmit
# 2. fit-v6-calibration.ts (calibration audit)
# 3. gesture-robustness.test.ts (HaGRID 500)
# 4. adversarial-challenger-1.ts (18 checks)
# 5. adversarial-challenger-2.test.ts (70 checks)
# 6. global-v4-adversarial.test.ts (G1-G11, 41 checks)
# 7. Python pytest -v (26 tests)
# 8. tools/soak-replay.ts (continuous clinical soak)
```

> **Never skip steps:** The CI flagship gate (`flagship-verification-gate`) requires all 8 steps green. Steps are ordered: typecheck → lint → build → test → calibration → gesture → challengers → global → Python → soak.

## TypeScript & Lint

- `tsconfig.json` has `strict: true`, `noEmit: true`, `noEmit` enforces type-check-only
- ESLint 9.x with `eslint.config.mjs` — run `npm run lint` before committing
- Path aliases: `@/` maps to `./src/` (defined in `tsconfig.json`/`paths`)
- `next-env.d.ts` is generated by Next.js — do not edit manually

## Python toolchain

- Python 3.10+ required
- Install test deps: `pip install -e ".[dev]"`
- Pytest runs: `npm run test:py` → `py -m pytest -v` (Windows) or `python3 -m pytest -v` (Unix)
- Digital Twin server: `npm run twin` → `py -m steadygate.twin --port 8765`
- MediaPipe model expected at `public/models/hand_landmarker.task`

- Two main jobs: `typescript-and-perception` + `python-digital-twin`

## Acyclic pipeline contract (architectural note)

> **Stage 4 runs BEFORE Stage 3B.** Stage 3B consumes the voluntary trajectory `y_clean`, tremor RMS `A_rms`, and `dyskinesiaLikelihood` output by Stage 4, guaranteeing intention layers evaluate stabilized biomechanics rather than trembling coordinates. This ordering is enforced by the verification suite and must not be reversed.

## Key constraints & quirks

- **Zero external cloud dependencies** — all perception runs locally (MediaPipe WASM in `public/`)
- **Frame budget**: `< 16.8 ms` total; internal budget `< 7.70 ms` (measured p50=0.409 ms, p95=0.888 ms)
- **Tremor attenuation**: ≥72% RMS reduction (3.5–14 Hz) — any perception change must re-benchmark
- **Safety invariants**: zero false activations; bare-hand false object blocks = 0/1030
- **Voluntary group delay**: ≤30 ms in [0, 2 Hz] band (measured 21 ms)
- **Intentionality access**: ≥95% first-attempt success across all 5 pathological profiles
- **Small Diffs Mandate**: Never rewrite entire files > 100 lines using `Write`. Always apply targeted diffs via `Edit` (< 50 lines) to avoid model timeouts.
